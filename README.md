Веб-сервер для управления задачами с поддержкой повторений. Реализован на Go с использованием SQLite.

 Описание проекта

Проект представляет собой бэкенд для планировщика задач. Позволяет создавать, редактировать, удалять задачи, отмечать их выполненными. Поддерживает периодические задачи с правилами повторения: ежедневно (`d N`), ежегодно (`y`). Реализована также возможность поиска задач по заголовку или комментарию.
